# Discovery themes

- `sandboxes` — agent runtimes, containers, microVMs and task-scoped environments.
- `multica-integrations` — projects that demonstrably integrate or extend Multica.
- `determinism-quality` — reproducibility, verification, audit and governed execution.
- `memory-knowledge` — memory, knowledge graphs, catalogs, provenance and retrieval.
- `observability` — logs, traces, diagnostics and relevant-context delivery.

For scheduled discovery, accept only identifiable upstream GitHub repositories with more than 100 stars and source-backed fit to at least one theme. Exclude mirrors and already registered repositories. Quality takes precedence over filling every theme.
